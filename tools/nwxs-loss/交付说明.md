## 四、使用说明

### 4.1 安装
```bash
# 1. 解压交付包
unzip nwxs-loss-calculation-skill-delivery.zip

# 2. 进入目录
cd nwxs-loss-calculation-skill-delivery

# 3. 安装依赖
pip install -r requirements.txt
```

### 4.2 运行
```bash
# 默认运行（完整输出）
python scripts/main_calculation.py

# 指定输入文件
python scripts/main_calculation.py -i your_data.json

# 仅生成JSON结果
python scripts/main_calculation.py -f json_only
```

### 4.3 输出格式
```
full (默认):      JSON + Excel + 图表 + HTML
summary:          JSON + Excel汇总
json_only:        仅JSON结果
```

```json

  "tables": {
    "dms_def_feeder": {...},
    "dms_def_source": {...},
    "dms_def_lnseg": {...},
    "dms_def_trfm": {...},
    "dms_def_trwd": {...},
    "dms_def_load": {...}
  }
}
```

### 5.2 必需数据表（6个）
```
1. dms_def_feeder  - 馈线定义

3. dms_def_lnseg   - 导线段定义
4. dms_def_trfm    - 变压器定义
5. dms_def_trwd    - 变压器绕组
6. dms_def_load    - 负荷定义
```
