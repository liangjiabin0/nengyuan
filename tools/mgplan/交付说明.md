## 二、当前程序架构

```text
scripts/openTEPES_Main.py
  ├─ check_mac()                         设备授权检查
  └─ openTEPES.openTEPES_run()
       ├─ InputData_poi                  从 config/ 读取 CSV
       ├─ SettingUpVariables_poi         定义变量
       ├─ openTEPES_ModelFormulation     构建目标与约束
       ├─ openTEPES_ProblemSolving       调用 Gurobi
       └─ openTEPES_OutputResults        写入 output/
```

路径约定：

| 角色 | 目录 | 解析方式 |
|------|------|----------|
| 输入 CSV | `config/` | `openTEPES_InputData._resolve_config_dir()` |
| 结果文件 | `output/` | `openTEPES_OutputResults._resolve_output_dir()` |
| 计算内核 / 求解器 | `scripts/`、`scripts/opt/` | `DIR = os.path.dirname(__file__)` |
| 案例名 | `sSEP` | `openTEPES_Main.py` 中 `CASE = "sSEP"` |

说明：

1. 主函数仍固定 `CASE = "sSEP"`、`SOLVER = "gurobi"`、`LOG = "Yes"`。
2. 主函数虽声明 argparse，但未调用 `parse_args()`，命令行参数不会生效。
3. `config/calculation_config.py` 仅作默认值说明，不覆盖主函数硬编码与 MAC 白名单。
4. 文件名仍使用 `_sSEP.csv` / `_sSEP` 后缀，与案例名一致。

## 五、使用说明

### 5.1 安装

```bash
cd mgplan-calculation-skill
pip install -r requirements.txt
```

另行完成 Gurobi 本地安装和授权配置。

### 5.2 运行

```bash
python scripts/openTEPES_Main.py
```

或：

```powershell
& "$env:AI4ES_PROJECT_ROOT\tools\mgplan-venv\Scripts\python.exe" `
  "$env:AI4ES_PROJECT_ROOT\tools\mgplan\scripts\openTEPES_Main.py"
```

运行前确认：

1. 目标设备通过 `scripts/openTEPES_Main.py` 的 MAC 白名单
2. `config/` 中存在全部必需输入 CSV
3. `output/` 可写（程序会自动创建该目录）

## 九、故障排除

```text
问题：MAC address is not correct
处理：联系程序授权提供方登记设备，不得绕过检查。

问题：无法导入 pyoptinterface 或 gurobipy
处理：安装 requirements.txt，确认 Gurobi Python 环境匹配。

问题：找不到 sSEP 输入
处理：确认 config/ 中存在对应 oT_Data_*_sSEP.csv / oT_Dict_*_sSEP.csv。

问题：模型不可行
处理：检查 output/ 或求解阶段生成的 IIS/ILP 诊断文件。

问题：网络地图未生成
处理：检查 Mapbox token、Plotly 和 Chrome renderer；CSV 结果仍可独立验收。
```
