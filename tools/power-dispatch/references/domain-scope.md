# Domain Scope

## 1. 研究范围

本 Skill 面向电力系统运行优化与协调控制计算，首要覆盖：

- 优化运行：经济运行、OPF、网损、电压偏差、可再生能源消纳、储能调度；
- 主配微：主网/上级电网、配电网、微电网的边界功率协调；
- 多时间尺度：日前、日内滚动、实时/准实时状态继承；
- P/Q 协同：有功、无功、电压、设备 P-Q 能力域；
- 自由组合：网络层级、时间尺度、控制维度、资源、目标、约束和算法插件的组合。

## 2. 首版非目标

以下能力可以作为插件，但不应在参考执行器中伪装成已完整实现：

- 电磁暂态；
- 保护整定与短路计算；
- N-1 安全约束 OPF 的完整工程实现；
- 分布式 C&CG / DRO / MPC / MARL 的论文级算法复现；
- 真实电网生产数据接口。

## 3. 工程原则

- 所有任务先形成 RunSpec。
- 所有数字结果来自数值后端，不来自语言模型。
- 标准算例与组合算例必须区分。
- 多目标权重必须显式。
- 多时间尺度状态必须显式继承。
- 近似优化必须声明模型精度并校核。
