# 证据、全文阅读、术语和指标规则

## 1. 资料状态与完整阅读

为每份资料维护：`NOT_STARTED`、`EXTRACTED`、`READING`、`FULLY_READ`、`SUMMARY_COMPLETE`、`VERIFIED`、`BLOCKED`。

只有满足以下条件才标记 `FULLY_READ`：已知总页数/章节；已处理首页、全部正文和末页；逐页/逐章有日志；相关图表公式、权利要求或条款已检查；关键判断有页码、章节、条款或权利要求号；未用摘要推断正文。

扫描件先检查隐藏文本层；双栏错序、乱码、表格错配或关键章节缺失也视为文本层不可直接使用。按 `source-extraction-and-web-supplement.md` 依次采用双引擎、版面重排、全页渲染、OCR或AI视觉核验。关键数值、公式、标准条款和专利权利要求必须回看页面图像；OCR证据标注引擎和页码。

## 2. 单篇总结

详细总结按资料类型完整记录：

- 论文：研究对象/边界、模型假设、方法、输入、算例/工程数据、量化结果、作者创新、实际贡献、局限、术语、可支撑与不可支撑内容、冲突和页码。
- 专利：法律信息、独立权利要求逐项拆解、从属限定、流程/系统、输入输出、保护范围、重叠路线、应回避表达和权利要求/页码。
- 标准：状态和替代关系、适用/不适用范围、术语、对象、电气量、强制/推荐/条件性要求、规划/运行/保护/通信/自动化/测试条款、可形成参数、不可直接模型化条款及条款号/页码。
- 国网指南：七段写法、课题逻辑、研究动作、指标、成熟度、应用、高频表达、不可照搬内容和重复边界。
- 工程/政策/网络资料：发布机构、发布日期、事实日期、工程对象、层级、系统、可核事实/数据、原始来源、可支撑和不可支撑内容、获取日期。

每份详细总结另压缩为一页版，至少包括资料 ID、书目信息、研究对象、方法/条款/权利要求、主要结果、局限、可支撑内容、不可支撑内容和证据定位。一页版不是重新推断，只压缩详细总结中的已核内容。

同一资料归入多个课题时，只维护一份唯一主总结，各课题副本由资料ID和哈希映射生成。不得在不同课题中对同一原文产生互相冲突的总结。

全部标准必须有版本核验字段：核对日期、当前状态、新版、替代关系、发布/实施日期、官方链接和使用结论。新版全文未取得时，只能报告替代元数据和补证需求，不推断新条款。

## 3. 总研究综述

总综述由单课题综述综合生成，包含：总体研究脉络、各课题现状、方法对比、专利拥挤区、标准边界、争议、研究空白、跨课题技术路线、指南写作理由和待补证。

在正文后设“按课题汇编的单篇资料总结”，收录全部 SHA-256 唯一资料的一页版。每篇从新页开始，原则上不超过一页；无法在一页内完整呈现时压缩措辞和表格，不删除证据定位。详细版放在对应课题中间成果目录，通过资料 ID 映射。

## 4. 术语来源和等级

来源优先级：全国科技名词委/术语在线；现行国标、行标、国网企标；正式国网指南和技术文件；同行评议论文；合法可访问数据库；专利；官方工程/政策资料。

无合法 CNKI 权限时记录“CNKI 不可用”，不得绕过登录或批量抓取受限全文。

- N：科技名词委审定、现行标准定义或正式行业/国网文件明确采用。
- A：多篇高质量论文或多份正式国网指南稳定使用且语义一致。
- D：由规范词组成的描述性表达，不包装为新概念。
- P：项目自定义概念，只能在配套说明中定义。
- X：无来源、含义不稳、多义、与规范冲突或模型生成的组合词。

项目名、课题名、关键技术名和指标对象的核心术语只能为 N/A。D 可用于目标和路线；P/X 禁止进入正式核心表述。

术语台账至少记录候选词、位置、含义、名词库/标准/指南/论文检索、典型搭配、多义性、替代表达、等级、结论、证据和页码。

## 5. 证据矩阵

每一条指南表述记录：位置、原表述（如有）、终稿表述、对象、课题、术语等级、证据 ID、来源类型、页码/条款、直接证据或综合推论、证据强度、使用边界、冲突、待验证和是否允许进入正式指南。

不得把综合推论标为直接证据。资料缺失、观点冲突、专利重叠和标准不适用均进入待补证或冲突表。

## 6. 指标口径

每项指标至少记录：验收对象、指标定义、公式、分子分母、有效样本条件、测试系统、场景、数据、基线、阈值来源、成功/失败条件、适用范围和证据 ID。

阈值来源依次优先：强制/推荐标准，已有工程验收口径，用户提供预试验/历史数据，同类正式指南的合理范围（仅作参考），项目可研标定。文献算例值不得直接成为阈值。
