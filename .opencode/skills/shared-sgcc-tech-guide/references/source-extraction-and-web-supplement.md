# 分类资料提取、PDF升级、网络补证与标准版本核验

## 1. 统一原则

从正文首页、题录页、权利要求书或标准封面解析题名，不用文件名替代正式题名。后台证据记录分开标注 `【原文证据】`、`【AI视觉核验】`、`【OCR核验】`、`【官方网络核验】`、`【第三方网络核验】`、`【综合归纳】`、`【网络补充候选】` 和 `【待补证】`；面向技术人员的高密度 Markdown 按 `dense-single-document-summary.md` 生成，不显示这些后台标签。外文资料形成中文总结并保留原文题名；机器翻译只用于表达，不改变证据属性、数值和页码。

同一资料可作为多个课题参考。先生成唯一主记录、详细总结和一页版，再按课题索引复制；各副本必须具有相同资料ID、哈希和正文。

## 2. PDF质量升级

先读取原生文字层并逐页记录字符数。出现以下任一情况即升级：双栏串行、标题正文混排、连续断词或乱码、表格行列错配、公式与变量说明错配、关键章节缺失、连续页面字符异常、文本与页面图像不一致。

升级顺序：

1. pypdf/pdfplumber双引擎提取；
2. 版面感知分栏和章节重排；
3. Poppler全页渲染；
4. 本地OCR、高质量MCP/开源解析器或AI视觉逐页核读；
5. 对公式、表格、标准数值和权利要求回看页面图像；
6. 仍不足时标记 `NEEDS_OCR_OR_AI_REVIEW`，不得标记 `SUMMARY_COMPLETE`。

OCR结果保留页码和引擎，修复汉字间异常空格，但不凭语言模型补造缺字、公式或表格值。

## 3. 论文模板

详细版依次包含：

1. 中文题名、原文题名、作者、期刊/会议、年份卷期页、DOI；
2. 研究问题、对象、系统边界和模型假设；
3. 核心理论、数学模型、输入、变量和约束；
4. 方法/算法步骤、复杂度和与基线的差异；
5. 数据、算例/工程对象、场景和评价指标；
6. 定量结果及其适用条件；
7. 作者创新与AI归纳的实际贡献，二者分开；
8. 结论节定位、局限、不得外推事项；
9. 对国网指南可支撑/不可支撑内容；
10. AI判断的网络补充方向和候选资料。

高密度 Markdown 只聚合后台已核内容，不重新推断；结构和优先级遵循 `dense-single-document-summary.md`。未找到结论节时，在后台写明已检查的末章标题和页码以及具体缺口；生产摘要只写能够确认的局限，不使用“结论段未被稳定识别”等占位句。

## 4. 专利模板

详细版依次包含：

1. 发明名称、公开/授权号、申请号、日期、申请人/权利人、发明人；
2. 官方法律状态核验结论；第三方状态不得冒充官方结论；
3. 独立权利要求逐项必要技术特征；
4. 从属权利要求的进一步限定；
5. 核心保护组合、输入输出、流程/装置模块；
6. 技术贡献、与项目路线的重合风险和差异化方向；
7. 说明书实施例能证明和不能证明的内容；
8. 同族、相近专利、年费/权利变更和FTO待补证。

核心保护以独立权利要求为主，摘要只用于理解技术背景。专利授权不等于工程性能验证。

## 5. 标准模板

详细版依次包含：

1. 标准号、中英文名称、性质、发布日期、实施日期、状态、主管/归口；
2. 新版、替代标准、全部/部分替代关系及切换日期；
3. 适用/不适用对象、接入电压、设备类型、运行方式和工况；
4. 术语及对象边界；
5. 按规划、接入、运行、有功、无功电压、保护、通信、自动化、电能质量和测试分类的条款；
6. 数值要求表，保留条款号、单位和适用条件；
7. 可转为项目接口/合规/测试边界的内容；
8. 不可直接转为算法创新、性能或通用指标的内容；
9. 引用标准的版本联动风险和待补全文。

推荐性标准中的“应、宜、可”保持原语气。数值不能脱离电压等级、接入位置、设备类型或场景引用。

## 6. 标准版本核验

对每个标准号在任务执行日查询全国标准信息公共服务平台、国家标准全文公开系统或主管机构。输出《标准版本核验表》，至少包含：

| 字段 | 要求 |
|---|---|
| 本地标准 | 标准号与年份 |
| 核对日期 | YYYY-MM-DD |
| 当前状态 | 现行、即将实施、废止或待官方核验 |
| 新标准 | 新标准号与年份 |
| 替代方式 | 全部代替、部分代替或无替代 |
| 发布/实施日期 | 分开记录 |
| 使用结论 | 当前可用、新版优先、换版窗口或停止引用 |
| 官方链接 | 直接链接到主管平台详情页 |

新版已发布但尚未实施时，同时写明旧版截至核对日仍有效和新版切换日期；项目实施/验收跨越切换日期时，必须取得新版全文并形成新旧条款差异表。只有官方来源可改变标准状态；搜索结果摘要只作导航。

## 7. 主动网络补证

联网不只修补DOI、年份或状态。对每篇资料检查指南论证链是否缺少：最新综述/趋势、核心理论、网络/物理约束、不确定性与动态过程、工程示范、测试验收、性能指标、知识产权、中国/国网适用性以及反证/失效条件。

网络候选使用 `NET-xxx` 编号并记录题名、类型、拟支撑内容、为何需要、全文取得状态、核对日期和链接。未取得全文的候选不得写成已核结论；纳入后按本文件相同模板形成独立总结。

## 8. 状态门禁

- `FULLY_READ + SUMMARY_COMPLETE`：正文已逐页/逐章处理，关键证据可定位，详细版和一页版完整。
- `FULLY_READ + SUMMARY_NEEDS_WEB_CHECK`：正文总结完成，但法律/标准时效元数据待官方核验；不得据未核字段下正式结论。
- `NEEDS_OCR_OR_AI_REVIEW + SUMMARY_INCOMPLETE`：关键正文尚未可靠取得。
- `BLOCKED + SUMMARY_INCOMPLETE`：文件损坏、权限不足或无可用提取路径。

严禁 `BLOCKED / SUMMARY_COMPLETE`、`NEEDS_OCR_OR_AI_REVIEW / SUMMARY_COMPLETE` 组合。

## 9. 禁用占位表达

总结正文不得出现“从文本中稳定识别”“结论段未被稳定识别”“以题名及正文对象为准”等无信息占位句。确有缺口时，写清已检查的范围、缺失字段、影响、补证方式和优先级。
