# 统一流程与成果组织

## 1. 推荐目录

```text
项目根目录/
├── 00_项目总体/
│   ├── 01_输入与范围
│   ├── 02_最新范例基线与重复边界
│   ├── 03_资料总清单与阅读日志
│   ├── 04_术语与工程背景
│   ├── 05_跨课题冲突与技术路线
│   ├── 06_总成果渲染与检查
│   └── 07_唯一资料主总结与网络补充
├── 01_课题1_实际名称/
│   ├── 00_范围依据
│   ├── 01_全文提取
│   ├── 02_单篇资料总结_详细版
│   ├── 03_单篇资料总结_一页版
│   ├── 04_单课题综述
│   ├── 05_课题设计说明
│   ├── 06_单课题指南
│   ├── 07_证据映射
│   └── 08_渲染与检查
├── 02_课题2_实际名称/
└── ...按实际数量继续
```

中间成果必须归入对应项目和课题；总体清单可建立索引，但不得用平铺副本替代课题归档。

## 2. 阶段流程

### 阶段 A：启动与基线

1. 扫描全部输入、模板、范例和课题目录。
2. 确定课题数及范围文件；记录缺失。
3. 确定最新国网范例和前一批次对照。
4. 完整阅读相关范例，生成写作基线和相近项目重复边界。
5. 有旧稿时提取批注/标黄/修订并转为当次约束；无旧稿时跳过。

### 阶段 B：证据处理

1. 建立资料清单、哈希去重和阅读日志。
2. 按论文、专利、标准、指南/工程资料分类全文提取；同一资料建立唯一主记录并保留全部课题归属。
3. 运行PDF质量门禁，必要时升级到全页渲染、OCR、MCP/开源版面解析或AI视觉核验。
4. 形成详细单篇总结和一页版，再按课题索引生成副本。
5. 主动联网核验题录、法律/标准状态和指南证据缺口；标准逐项形成版本替代检查。
6. 建立原子证据、资料准入评分和六类课题证据覆盖矩阵；缺口生成 NET 搜索任务。
7. 完成论文—专利—标准技术特征映射、标准依赖监测、专利权利要求特征矩阵、工程背景、网络补充候选和术语台账。

### 阶段 C：课题研究设计

1. 仅在该课题全部非重复资料完成阅读和总结后形成单课题综述。
2. 形成工程矛盾、研究空白和项目增量三张表，明确研究什么、不研究什么、与其他课题接口及与已有成果差异。
3. 设计三个递进研究点，为每点绑定原子证据 ID、输入、变量、方法、输出和验证。
4. 形成单课题指南、指标卡及指标口径表。

### 阶段 D：综合与成稿

1. 检查研究对象、方法、输入输出、指标和成熟度的跨课题冲突。
2. 生成至少 3 个项目名候选，比较术语等级、两类协同体现、重复度、自造词和长度。
3. 合成应用场景、功能需求、关键技术、课题内容和成果应用。
4. 将功能需求、关键技术和课题按相同顺序一一对应；每个课题整理为三个递进研究点及“性能—验证—产出”三段指标。
5. 按 `fixed-guide-format.md` 将内容写入结构化 JSON，用 `scripts/build_fixed_guide.py` 和固定母版生成 DOCX；不得从空白文档重建，不得使用表格承载指标。
6. 总综述附按课题编排的全部一页式单篇总结。

### 阶段 E：质检与交付

1. 用 Word 或 LibreOffice 更新目录域、页码和交叉引用，重新分页并导出 PDF。
2. 清除标黄、批注、修订、编辑括号、占位符和异常空格。
3. 渲染每页并视觉检查封面、目录、指南组页、项目标题、课题块、页码和末页；检查 DOCX/XLSX ZIP 完整性。
4. 运行 `scripts/check_guide_docx.py` 固定格式检查，并按 `qa-checklist.md` 判定是否可宣称完成。

## 3. 建议成果包

正式成果按用户版本后缀命名：

- 国家电网总部科技项目申报指南_Vx.docx
- 研究综述_Vx.docx（含全部一页式单篇总结）
- 标准与参考文献_Vx.docx，并提供标准 BibTeX（用户要求时提供 Markdown/LaTeX）
- 证据矩阵_Vx.xlsx
- 术语规范报告_Vx.docx
- 待补证清单_Vx.xlsx
- 证据系统与指南编制台账_Vx.xlsx
- 旧版-新版修改说明.docx（仅内部审阅，有旧版时生成）

中间成果至少包括资料总清单、阅读日志、详细/一页单篇总结、单课题综述、课题设计说明、单课题指南、证据映射、跨课题冲突消解、渲染图和质检报告。

另须保留唯一资料主总结目录、原子证据库、准入评分、六类覆盖矩阵、三类证据映射、工程矛盾—研究空白—项目增量表、指标卡、构建清单、PDF提取质量报告、OCR/AI核验日志、翻译日志、网络补充资料表、标准依赖和版本核验表、专利权利要求特征矩阵及新旧标准差异表（取得新版全文时）。正式研究成果分为决策版综述、全部一页总结汇编和详细证据附件。

## 4. 断点与完成度

断点记录最后处理的资料 ID、页码/章节、下一位置、提取方法、问题和输出路径。最终回复报告实际课题数、资料总数/唯一数、完整阅读数、总结数、术语替换/淘汰数、CNKI 使用情况、课题综述完成情况、质量门槛结果、文件路径和未解决问题。
