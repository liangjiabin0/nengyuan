# 可复用规定与注意事项

以下规定由既往指南批注、返工和 V2/V3 校核问题抽象而成。它们是今后每次任务的永久检查项，不要求当次存在 V2 或问题清单。

## 1. 输入与范围

1. 不预设项目课题数量，以实际一级课题目录和用户范围文件为准。
2. 个人研究方向、课题范围或撰写指引是最高优先级边界；资料数量多不能扩大该边界。
3. 旧稿、批注和标黄是可选输入。有则逐条吸收，无则不创建形式化的“旧版问题清单”。
4. 用户明确排除的资料类型不得进入正式证据。对项目特定排除项建立清单；不要把某项目的排除项误升格为所有项目的永久禁区。
5. 通信、数据、人工智能等内容只有在用户范围和证据允许时进入，并必须落到电网业务对象、变量、状态或测试判据。不得因资料中出现这些词就自动设为核心课题。

## 2. 项目定位与逻辑

1. 全文只围绕一个可清楚表述的核心工程矛盾展开。
2. 同时说明涉及的电网层级和一次/二次关系，不靠重复写“主配微”“一二次协同”冒充对象明确。
3. 每次出现跨层级协同，至少明确一项：接口、交换功率、电气量、信息、控制指令、资源聚合、责任边界或异常状态关系。
4. 每项研究回答：对象、层级、电气量/状态/变量、工程问题、输入、输出和验证方式。
5. 课题形成有向技术链。上一课题输出必须能成为下一课题输入；末端验证结果应说明反馈对象。
6. 关键技术与课题一一对应；正文不得出现无课题承接的关键技术或无关键技术来源的课题。

## 3. 专业边界

1. 不把通用文本结构化、知识图谱、规则引擎、自然语言处理、数据治理、版本管理或证据链管理独立包装成电力系统核心创新。
2. 标准研究必须映射到设备对象、拓扑、电气参数、潮流/安全约束、运行限值、接入要求、控制模式、测试场景或验收判据。
3. 标准条款不能未经适用性分析直接等同为优化模型约束。
4. 仿真平台必须服务于具体规划、运行、控制或试验问题，不得脱离研究对象成为一般软件研发。
5. 论文算例、专利方案和标准要求应区分：论文说明研究可行性，专利限定已有保护路线，标准规定适用条件与要求，三者不能互相替代。

## 4. 术语禁则

1. 不得因表达顺口就认定为专业术语，不得用组合词制造创新感。
2. 既往问题词如“可靠兑现”“运行能力兑现”“能力契约”“可调用能力边界”“标准约束数字化”“机器可执行转换”“全链路仿真”“测试证据包”“可行方案回退”必须重新检索，不能默认沿用。
3. 找不到 N/A 级术语时，用规范词组成描述性短语，不创造四字概念。
4. 新术语如确需保留，只能作为 P 级在配套研究说明中定义，不进入项目名、课题名、关键技术名或核心指标名。
5. 同一对象、层级和量在全文使用同一名称；术语台账必须记录替换前后、来源和页码。

## 5. 各部分对应关系

1. 应用场景提出具体业务过程中的问题和后果，不写算法清单。
2. 功能需求归纳项目需要具备的业务能力，不混入实施方案。
3. 关键技术说明为满足需求需攻克的技术，并与课题顺序一致。
4. 课题预期目标写具体研究动作、成果形态和上下游接口。
5. 考核指标只验收预期目标已承诺的成果，不新增研究内容。
6. 成果应用明确使用单位/专业、业务环节、输入成果及解决的问题，不只写“具备推广应用条件”。

## 6. 课题写法

1. 每个课题原则上设三个肉眼可辨的递进研究点：机理/对象/模型，核心方法，方案/工具/验证。
2. 三点不能只是并列名词；每一点均写对象、输入、变量、方法、输出和验证。
3. 课题标题覆盖正文全部核心对象，正文不得超出标题范围。
4. 少用连续长串并列名词；优先使用“分析、揭示、建立、构建、提出、研究、形成、研发、验证”。
5. 不使用宣传式词语和无对象的“构建体系、形成模型、实现协同、提升能力”。

## 7. 指标与成熟度

1. 每课题突出 1 至 3 个核心技术/性能指标，再列验证规模和必要成果产出。
2. 比例指标必须给出分子、分母、样本/场景集合、统计周期、成功条件和失败判定。
3. “精度提升、失败率降低、时间缩短”等比较指标必须给出同数据、同场景的基线方法。
4. 不为显得先进设置缺乏测试条件的百分比、微秒级范围或 100% 追溯率。
5. 专利、论文、软著、标准、报告和示范数量与经费、周期、课题工作量匹配，避免成果承诺堆叠。
6. 不把所有成果一律设为期末 7 级。基础模型/算法、软件模块、装置和示范系统分别确定成熟度及验证环境。

## 8. 文档与版本

1. 不覆盖原始文件；以模板副本生成新版本。
2. 保留封面、目录、页眉页脚、页码、章节、字体字号、缩进、行距、页边距、分页和非技术字段。
3. 目录项目名与正文完全一致；清除批注、修订、标黄、TODO、编辑括号和异常空格。
4. 中间成果放入对应项目/课题目录，不把所有课题文件平铺在总目录。
5. 总研究综述按课题附全部唯一资料的一页式总结；详细总结仍保留在课题目录，并用资料 ID 对应。
