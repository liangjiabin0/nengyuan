# 技术参考来源映射模板

## 来源类型说明

- **A 直接采用**：同类对象、同类问题，方法可直接使用。
- **B 适应性迁移**：对象或边界不同，需要修改模型、约束或参数。
- **C 多源融合**：组合多篇文献中的互补模型。
- **D 拟拓展**：文献没有直接完成，是新的研究设计。

## 文字说明模板

> **技术参考来源：** 【模块A】直接参考【作者】等（年份）提出的【方法】，该方法原用于解决【原问题】；本研究将其用于【当前问题】，属于【A/B】类来源，需要增加【适应性改造】。\[编号\] 【模块B】综合【作者1】的【方法1】与【作者2】的【方法2】，属于C类多源融合。\[编号组\] 将【新增状态/约束/系统层级】纳入统一模型属于D类拟拓展，不能表述为上述文献已经实现。

## 自检

- [ ] 每个研究内容至少有一项来源。
- [ ] 每个算法名称均有来源或标记为通用理论/拟拓展。
- [ ] B类来源写明对象差异和改造内容。
- [ ] C类来源说明各文献分别贡献什么模块。
- [ ] D类来源没有使用“文献表明该方法已实现”的措辞。
