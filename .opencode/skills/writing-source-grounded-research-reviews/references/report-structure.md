# 研究综述—难点—研究内容—技术路线报告结构

## 1. 总体结构

默认报告采用以下结构。研究方向数量可调整，但每个方向内部结构保持一致。

```text
封面
摘要
关键词
编制说明
目录

1 研究背景、文献范围与分析框架
  1.1 研究任务与对象边界
  1.2 文献来源、筛选与分类
  1.3 综述方法、证据等级与引用规则
  1.4 总体研究逻辑

2 研究方向一：……
  2.1 研究主题界定与综述目标
  2.2 文献综述
    2.2.1 子主题A
    2.2.2 子主题B
    2.2.3 子主题C
    2.2.4 小结：现有研究的演进与边界
  2.3 现有研究不足
  2.4 关键难点问题
  2.5 具体研究内容
  2.6 解决思路与技术路线
  2.7 技术参考来源映射
  2.8 验证方案、预期创新与成果

3 研究方向二：……
  （结构同上）

4 研究方向三：……
  （结构同上）

5 各研究方向的协同关系与总体技术路线
  5.1 输入—处理—输出关系
  5.2 模型、数据和算法接口
  5.3 总体技术路线
  5.4 阶段任务与成果

6 结论与需要补充的文献/数据

参考文献
附录A 文献证据矩阵
附录B 技术来源映射表
```

## 2. 各部分内容契约

### 摘要

摘要应包含：

1. 文献范围与研究对象；
2. 主要文献演进；
3. 核心不足和难点；
4. 拟研究内容；
5. 总体技术路线与成果形态。

摘要中不堆砌模型缩写，不引入正文未讨论的新结论。

### 1.1 研究任务与对象边界

明确：

- 研究对象及层级；
- 场景边界；
- 时间尺度；
- 与相邻领域的边界；
- 用户文献与外部补充资料的使用范围。

### 1.2 文献来源、筛选与分类

说明文献数量、年份分布、对象分布、主题分类和筛选原则。建议用三线表展示文献分类，但不以表格替代正文综述。

### 1.3 综述方法

说明证据卡、主题聚类、比较维度、证据等级和引用方式，使报告的方法可复核。

## 3. 每个研究方向的固定结构

### X.1 研究主题界定与综述目标

用一段话回答：本方向研究什么、为什么需要单独综述、与其他方向如何衔接。

### X.2 文献综述

按2—5个子主题组织，每个子主题至少包含：

- 主题引导句；
- 作者—年份式代表研究；
- 方法和结果；
- 比较与演进；
- 局限或适用边界。

本节只写已有研究及有证据的比较，不提前写拟研究方案。

### X.3 现有研究不足

建议3—6项。每项包含：

1. 已有研究达到的能力；
2. 尚未覆盖的环节；
3. 对当前研究对象造成的影响；
4. 支撑文献。

示例：

> 现有研究能够依据台风、高温或沙尘强度构建设备时变故障率，但多以单灾种和电气元件为主，未形成灾害、通信、控制及源荷储状态的共同致因事件链，因而可能低估复杂场景下群发故障和控制失效风险。\[6-8,15,21\]

### X.4 关键难点问题

每个难点按以下顺序写：

- 难点名称；
- 具体表现；
- 形成原因；
- 现有方法为何不足；
- 需要突破的理论或技术矛盾；
- 文献来源。

难点不能简单重复“研究不足”。

### X.5 具体研究内容

每项研究内容至少包含：

- **研究点名称**；
- **研究对象与核心问题**；
- **输入数据与状态/决策变量**；
- **拟建立的模型**；
- **拟采用的方法或算法**；
- **预期输出**；
- **验证方式**；
- **技术参考来源**；
- **相较现有研究的增量**。

研究点名称推荐：

- “考虑……的……建模方法研究”；
- “计及……耦合影响的……评估方法研究”；
- “面向……的……协同规划模型研究”；
- “融合……与……的……求解方法研究”；
- “面向……应用的……工具模块研发”。

### X.6 解决思路与技术路线

先给出总体思路，再分步骤展开。每一步必须包含：

| 字段 | 要求 |
|---|---|
| 输入 | 数据、场景、模型或上游结果 |
| 核心处理 | 建模、算法、仿真或决策过程 |
| 输出 | 可交付结果或下游接口 |
| 技术来源 | 作者、年份、编号与来源类型 |
| 验证 | 对比、消融、敏感性、样本外或工程验证 |

文字流程示例：

> 数据治理与场景定义 → 致灾因子和元件脆弱性建模 → 相关故障与状态演化 → 运行/恢复仿真 → 韧性指标计算 → 薄弱环节识别 → 规划优化 → 规划后再评估 → 工具化封装与应用验证。

### X.7 技术参考来源映射

用表格将研究内容和技术来源一一映射：

| 研究内容 | 关键技术 | 来源文献 | 来源类型 | 适应性改造 | 拟创新部分 |
|---|---|---|---|---|---|

### X.8 验证、创新与成果

验证方案至少包括：

- 标准算例或基准数据；
- 复杂组合场景；
- 实际或准实际案例；
- 对照方法；
- 评价指标；
- 灵敏度、消融和样本外测试；
- 计算性能或软件验收。

创新表述采用：

> 现有研究通常……，但尚未充分解决……；本研究拟在××文献方法基础上，通过……实现……。

## 4. 总体协同章节

说明各方向不是并列拼接，而是形成闭环：

```text
文献与数据 → 场景/机理模型 → 评估与诊断 → 研究内容/规划决策
→ 仿真验证 → 结果回写 → 模型校准 → 工具与工程应用
```

明确各方向的输入、输出、共享数据字典、模型接口和版本关系。

## 5. 表格使用原则

适合表格：文献分类、难点对应关系、研究内容汇总、技术来源映射、验证方案。

不适合表格：完整文献综述。综述主体必须用连贯段落体现研究演进和比较关系。
