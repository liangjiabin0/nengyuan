# 文献解析、证据矩阵与引用来源规范

## 1. 文献解析顺序

### 1.1 建立文献清单

对压缩包、文件夹或附件执行以下处理：

1. 记录文件名、文件类型、页数、可解析状态。
2. 从题名页、摘要页或文末参考信息提取题名、作者、年份、期刊/学位机构、卷期页码、DOI。
3. 按 DOI、完全相同题名、作者—年份—题名组合去重。
4. 对扫描件先使用页面视觉读取；只有文本和视觉读取均失败时才使用OCR。
5. 无法确认的字段标记“待核”，不得猜测。

### 1.2 单篇证据卡

每篇文献至少记录：

| 字段 | 内容要求 |
|---|---|
| 文献ID | 临时ID，最终编号确定后映射 |
| 题名/作者/年份 | 原文信息 |
| 研究对象 | 单微电网、互联微电网、配电网、综合能源等 |
| 场景与边界 | 灾害、运行状态、时间尺度、空间尺度 |
| 核心问题 | 文献试图解决的问题 |
| 模型与变量 | 物理模型、状态变量、决策变量、目标与约束 |
| 方法与算法 | 评估、优化、仿真、数据驱动或求解方法 |
| 数据与算例 | 数据来源、节点系统、工程案例 |
| 主要结果 | 定性结论与原文明确的定量结果 |
| 明确局限 | 作者在正文或结论中直接指出的不足 |
| 综合局限 | 与其他文献比较得到的不足，须标注“综合判断” |
| 可迁移技术 | 可用于后续研究内容或技术路线的组件 |
| 证据位置 | 页码、章节、表格、图号或可定位段落 |
| 证据等级 | E1—E4，见下文 |

## 2. 证据等级

- **E1 直接事实证据**：文献明确描述的方法、模型、数据、结果或结论。
- **E2 直接局限证据**：文献在结论、讨论或展望中明确提出的不足。
- **E3 可迁移方法证据**：方法来自相邻对象或领域，迁移到当前对象前需说明适应性改造。
- **E4 综合推断**：由多篇文献比较形成的判断。正文必须写明“综合来看”“对比可见”或“本报告判断”。

E4不能冒充E1或E2。拟研究内容通常建立在E2—E4上。

## 3. 技术来源分类

每个研究内容、解决思路和技术路线步骤都必须标记以下一种或多种来源类型：

| 类型 | 定义 | 推荐表述 |
|---|---|---|
| A 直接采用 | 文献对同类对象已使用该方法 | “直接参考××等（年份）的……方法” |
| B 适应性迁移 | 文献对象不同，需修改边界或约束 | “借鉴××等（年份）的……框架，并针对微电网……进行改造” |
| C 多源融合 | 将多篇文献中的互补模块组合 | “综合××的场景模型与××的恢复模型，形成……” |
| D 拟拓展 | 文献未直接提出，是基于证据链的新设计 | “在上述方法基础上的拟拓展，现有文献未直接完成该组合” |

技术来源字段示例：

> **技术参考来源：** 场景筛选直接参考周晓敏等（2018）的信息熵方法\[21\]；故障演化借鉴荣俊杰等（2024）的多时间尺度状态转移框架\[8\]；将通信状态与储能能量状态并入统一事件链属于在两类方法基础上的拟拓展。

## 4. 引用编号规则

### 4.1 默认标准

- 默认采用 GB/T 7714—2015 顺序编码制。
- 参考文献按正文首次出现顺序编号。
- 正文编号使用方括号并设为上角标，如上角标`[1]`、`[2-4]`、`[2,5,8]`。
- 同一事实由多篇文献共同支持时，引用最相关且足够的文献，不机械堆满全部文献。

### 4.2 引用位置

- 方法事实：放在方法描述后。
- 定量结果：紧跟数字和单位。
- 作者明确局限：放在局限句后。
- 段落综合判断：放在综合判断句后，列出支撑比较的文献。
- 技术路线来源：放在每个步骤的“技术来源”栏或句末。

### 4.3 页码与定位

内部证据矩阵必须记录页码或章节。正式报告是否展示页码由用户要求决定。对于直接引语、关键公式、复杂模型或争议性判断，建议在脚注或正文中增加页码。

### 4.4 引用一致性

交付前检查：

1. 正文每个编号在参考文献表中存在。
2. 参考文献表中不存在未被正文引用的条目，除非用户要求扩展阅读。
3. 编号连续、无重复、无跳号。
4. 引用范围能够正确展开，例如`[3-5]`代表3、4、5。
5. 作者—年份与对应编号的条目一致。
6. 同一文献不因中文/英文题名差异重复编号。

可运行：

```bash
python scripts/check_citation_consistency.py report.docx --format text
```

## 5. 文献来源边界

### 5.1 仅基于用户文献

报告应明确：

> 本报告的直接证据来源仅限用户提供的文献。通用理论用于解释研究逻辑时单独标注，不作为所给文献的直接结论。

### 5.2 允许外部检索

外部来源与用户文献分开标识：

- 用户文献：作为主要证据；
- 外部研究：标注“补充检索”；
- 模型推断：标注“综合判断”或“拟拓展”。

不得用外部文献悄然替换用户给定文献的术语、边界和结论。

## 6. 参考文献解析注意事项

- 题名中可能含年份，不要简单取第一个四位数；优先根据题名后的来源字段识别出版年。
- 网络首发文献同时记录网络首发日期和正式卷期状态。
- 中文作者以逗号分隔，英文作者可能包含缩写和复姓，脚本结果需人工复核。
- 学位论文、会议论文、标准、报告和专利采用对应文献类型标识。
- DOI缺失不影响引用，但不得自行生成。
- 脚本输出是初始清单，不替代人工核对原文首页。

## 7. 不受支持内容的处理

文献不足时使用以下表达：

- “所给文献未提供该参数的实测数据。”
- “现有文献能够支持该方法框架，但不足以证明其在本对象上的效果。”
- “该组合属于拟研究方案，不能表述为既有研究结论。”
- “需要补充通信韧性/网络攻击/实际故障数据等专题文献。”

不得用“通常认为”“显然”“众所周知”掩盖证据缺口。
