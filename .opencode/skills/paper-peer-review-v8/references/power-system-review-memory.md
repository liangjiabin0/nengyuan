# 电力与能源论文的可复用评审经验

这些规则来自人工补强、原文复核和审稿人复现纠错，适用于首次评审和重评。它们是按证据触发的检查，不是预置缺陷。每项判断仍须回到当前论文核验。

## 使用方式

每次评审先读 M01–M04，再根据论文实际方法和主张选择后续规则。在 `knowledge_application` 中记录规则、触发条件、原文位置、核验范围与结果；没有对应方法时标为不适用，资料不足时标为无法核验。

| 论文特征或评审材料 | 相关规则 |
|---|---|
| 人工批注、修订、旧意见 | M01、M02，按科学内容继续选择 |
| 概率预测、相关场景、双向备用、机会约束 | M05–M08 |
| 分段响应、整数逻辑、缩小算例 | M09–M11 |
| 可靠容量、备用市场、费用分摊 | M12–M14 |
| 工程应用、泛化、性能优势、机制归因 | M15、M16 |

规则正文集中维护在本文件；分类协议负责选择，报告模式负责记录。只保存通用条件、检查方法与验收依据；原始人工意见、作者身份、私有材料、单篇论文数值和判决留在任务资料中。

## 所有评审共用

### M01 人工反馈与版本身份

- **触发**：人工增强意见、批注、修订、作者回复或旧稿。
- **核验**：用 `scripts/extract_review_feedback.py` 提取评论锚点、插入/删除和接受修订正文；反馈也可能直接写在正文。按段落合并碎片修订，区分表达调整、事实纠正、科学核查、交付要求。人工反馈不是作者回复；“没读懂”需要解释技术关系，不能原样作为科学缺陷。
- **完成条件**：“反馈原句/锚点→意图→原论文证据→核验→评语行动”可追溯。反馈落实状态与作者解决科学问题的状态分别记录。原稿未变时不声称论文已修改；仅更新 skill 时处理通用经验，不自行启动整篇重评。

### M02 旧结论复核与证据定位

- **触发**：沿用旧评语、声称信息缺失、印刷公式疑点或要求具体算例证据。
- **核验**：检查全文、附录、图表和补充材料，确认提取失败不是原文缺失。重查旧问题涉及的分布、损失、零点、连续性、绝对值、日内更新及考核。区分原文事实、审稿人推断和运行发现；印刷公式错误不自动证明代码或结果错误。
- **完成条件**：定位节、式、表、图，必要时给指标和差值；撤回被原文反证的旧问题，未核实的实现后果使用条件性表述。不得保留“论文XX”等占位，不由逻辑完整推断结果有效。

### M03 符号含义与参数配置分开

- **触发**：重要公式、算法或实验存在定义疑点。
- **核验**：查首次使用、符号表、上下文与附录。只有确实未说明含义的符号/索引进入未定义符号表（最多三项，可零项）；已有含义但缺数值、范围、配置进入参数/复现障碍；关系不唯一列模型歧义。人工示例 lambda 不是当前论文缺陷证据。
- **完成条件**：每个展示公式解释所有符号的含义、单位、索引、维数、方向、定义域及前提。区分原文公式、合并记号、修正建议与审稿人模型；审稿人新增权重不算作者遗漏。

### M04 专业表述与配对交付

- **触发**：人工质疑术语准确性、可读性或报告一致性。
- **核验**：使用物理量、主体、运算和验证条件解释关系。例如将“容量质量”具体化为持续可调用能力和可靠性贡献；“网络可交付性”解释为调用后的潮流、爬坡、SOC及持续响应校核；“气象预见性”解释为决策时可获得气象预报的条件预测。术语遵循当前论文定义，不机械推广某次措辞修改。
- **完成条件**：主要意见有影响、最小充分行动及验收条件；Markdown/Word共享规范内容并逐页核验公式，中英文科学结论一致。重评更新数字、JSON和图表，PPT及报告按用户范围交付。

## 概率预测、场景与风险

### M05 相关场景变换的矩阵含义

- **触发**：协方差/相关矩阵、Cholesky、Nataf或高斯 copula。
- **核验**：“矩阵分解→线性变换→标准正态CDF→边缘逆CDF”中，分清带量纲物理协方差与潜在高斯相关矩阵。标准正态CDF的输入各分量应为标准正态；物理协方差需标准化。潜在高斯相关不自动等于输出物理Pearson相关，检查半正定性及边缘/相关匹配。
- **完成条件**：变换定义、拟合参数和输出校核可重建；仅纸面疑点时提出条件性风险，核实实现后判断实际影响。

### M06 概率校准、训练协议与信息时间

- **触发**：分布、方差、区间预测或气象辅助决策。
- **核验**：展示区间不等于校准；检查隔离测试期的覆盖率、区间宽度/适当评分及必要分组。已有高斯NLL时聚焦结构、方差正值处理和训练协议，不再声称损失缺失。气象信息、预处理统计量和特征选择只能使用决策时可取得的信息。
- **完成条件**：时间切分、模型选择与敏感参数可重建；跨时间/场站泛化有相应迁移测试，随机划分同一时段不能替代。

### M07 概率对象与预算

- **触发**：双向分位、机会约束、条件越限率或全年风险外推。
- **核验**：区分单侧、双侧、单时段、联合轨迹、天气条件和全年统计，核对概率权重、持续时间及分母。在一致连续分布的分位定义下，两端各95%单侧覆盖通常对应中央约90%覆盖，不是95%联合保证。高峰条件越限率不能直接当作全天/全年统计。
- **完成条件**：保证对象、预算、条件事件和聚合权重明确，经验超额频率与理论保证分别报告。

### M08 风险指标与量纲

- **触发**：缺额频率、条件/无条件缺额、EUE、CVaR。
- **核验**：同一非负缺额随机量的条件均值乘事件概率得到无条件均值；MW转MWh需乘持续小时数并按概率汇总。事件频率和严重度分别报告，标准差不是置信区间。
- **完成条件**：指标口径和单位一致；一项改善不推断全部风险改善，收益—风险折中不写成全面优越。

## 分段模型、优化与复现

### M09 分段训练与执行一致

- **触发**：分位分段、正负子集、时变响应或逐段训练。
- **核验**：检查子集权重归一化、重复分位、空区间、零值、端点、区间外需求及单侧极限。训练与执行共享冻结边界和编号，每个使用段有样本或默认处理；不能用三段训练编号评估五段规则。比较全天固定、逐时单段和逐时多段前核对自由度，K=1不自动等于全天固定。
- **完成条件**：边界、编号和端点闭合；用指标差值、耗时和样本外表现解释复杂度增益，不以段数更多直接判优。

### M10 逻辑、容差与求解状态

- **触发**：Big-M、二元逻辑、严格不等号、物理触发、二分或启发式搜索。
- **核验**：平滑阈值不自动是Big-M；说明物理界限和求解容差。“非负弃水触发满库/满出力”等须查零值是否错误触发。可行、证实不可行、限时未知和最优性证明分开；未知状态不能作为不可行更新二分区间，启发式最佳可行解不能未经证明称全局最优。
- **完成条件**：记录求解状态、残差、上下界/间隙和停止准则，结论匹配实际保证层级。

### M11 复现边界与审稿人实现自检

- **触发**：替代数据、缩小模型、局部试验或旧复现代码。
- **核验**：先检查审稿人索引、单位、冻结边界、状态判读和指标，再归因于论文。结构等价小例保留原目标、变量类型、关键物理约束、时序/不确定性和核心机制；删掉关键部分仅称局部机制试验。先校验可行残差和独立目标，再解释排序。
- **完成条件**：注明保留/删除组件、替代数据及假设；共享测试样本，训练/测试随机流隔离，必要时重复种子。未执行检查不写成运行结果，局部试验不能反证完整作者模型。

## 容量、市场与费用

### M12 可靠容量与等可靠容量

- **触发**：装机、申报、可调用容量或EUE比例折算。
- **核验**：区分装机、名义可申报备用、实际可调用、可靠系数折算与等可靠容量。实际/理想EUE改善量之比乘名义容量是比例折算；EUE对容量非线性时通常不等于等可靠容量。若主张风险等价，应在一致系统条件下求解相等风险容量或给比例成立条件。
- **完成条件**：检查零分母、负改善、越界、持续响应、SOC/能量约束和资源组合；工程指标可通过限定名称及用途解决。

### M13 采购目标、支付与机制主张

- **触发**：报价出清、统一边际结算、可靠系数或收入充足。
- **核验**：报价乘中标量的优化目标与统一边际价格结算分开；分别算容量支付、调用支付、违约扣减和总收费。收入充足明确主体：运营方收支守恒或参与者成本覆盖。可靠系数同时进入容量边界和支付不自动错误，核对价格容量基准及两个作用；机制性质按作者实际声明审计。
- **完成条件**：金额、容量、时间可对账，市场主张有证明/案例，物理可执行性有调用后的设备及网络校核。

### M14 费用归一化与公平

- **触发**：比例权重、改进Shapley、预算平衡或公平声明。
- **核验**：权重除以权重和再乘总费用，在非零分母下已预算平衡；先直接求和，不重复称费用不守恒。检查零分母、负权重/收费、联盟重算及加权后实际声明的性质。
- **完成条件**：预算平衡与公平分别评价；对必要公平主张给证明/小例和对照，不机械要求所有Shapley公理。

## 工程证据与性能解释

### M15 匿名工程、算例来源与适用范围

- **触发**：匿名基地、保密数据、工程或实用化声明。
- **核验**：匿名名称本身不是缺陷。检查参数、数据字段、采样时段、边界和约束，允许匿名统计、代表性样本或公开替代验证。真实数据、标准系统和合成案例分别标明。典型日、连续24小时、独立合成场景不等于跨年度部署，审稿人模拟不替代作者工程证据。
- **完成条件**：限定已验证运行条件；额外实验针对实际声明，收窄结论足够时不要求无关场景或披露身份。

### M16 性能优势、机制归因与文献

- **触发**：性能优越、复杂规则增益、机理解释或最新对照。
- **核验**：核对任务、输入、自由度、硬件、容差、预算和样本；保留已有对照、压力测试、敏感性及附录证据。小幅收益与优化间隙、物理近似和抽样波动比较；机制归因用能隔离该因素的对照。文献记录期刊/会议/预印本、年份、版本、关系及引用/实证比较状态。
- **完成条件**：结论定位到指标和证据范围。投稿日期未知时`available_before_submission=null`，不从文件名推断；投稿后研究不作不公平遗漏惩罚。正式三篇各有合法PDF或未获取记录，用户指定3–5篇时另列扩展清单和下载链接；未读全文不判内部公式优劣。
