# 强制质量门槛

## A. 证据与范围

- [ ] 实际课题数量来自扫描，不是预设。
- [ ] 每个正式课题有用户范围依据。
- [ ] 所有非重复本地资料有资料 ID 和 SHA-256。
- [ ] 所有正式结论所用资料均为 `FULLY_READ`、`SUMMARY_COMPLETE`。
- [ ] 不存在 `BLOCKED / SUMMARY_COMPLETE` 或 `NEEDS_OCR_OR_AI_REVIEW / SUMMARY_COMPLETE` 组合。
- [ ] 所有唯一资料均有详细总结、高密度 V7 和一页版，三者资料 ID 一致。
- [ ] 同一资料跨课题副本的资料ID、SHA-256和正文一致。
- [ ] 论文、专利、标准分别使用对应模板，题名来自正文或权威题录。
- [ ] PDF存在双栏错序、乱码、表格错配或关键章节缺失时已升级提取并保留OCR/AI核验日志。
- [ ] 每个课题有独立综述；总综述按课题收录全部一页版。
- [ ] 工程事实有发布机构、发布日期/事实日期和原始来源。
- [ ] 标准版本核验表覆盖所有标准，并记录核对日期、当前状态、新标准、替代关系、实施日期和官方链接；项目跨换版日时已取得新版全文或列为最高优先级待补证。
- [ ] 网络补充资料以 `NET-xxx` 独立编号，原文、官方网络核验、第三方信息和综合归纳未混写。
- [ ] 正式总结不存在“从文本中稳定识别”“结论段未被稳定识别”“以题名及正文对象为准”等无效占位表达。
- [ ] 每项资料均有八维准入评分、评分理由和 A/B/C/D 使用结论。
- [ ] 每项资料至少有一条可定位的原子证据，证据 ID 唯一，来源属性和不可外推边界齐全。
- [ ] 每个课题完成理论、方法、工程、标准、专利和反证六类覆盖评分；低于充分覆盖的类别有 NET 搜索任务。
- [ ] 已形成论文—专利—标准技术特征映射，三类证据未互相替代。
- [ ] 标准版本监测保存前后状态和规范性引用联动风险；专利形成独立权利要求特征矩阵。

## B. 范例与重复边界

- [ ] 已按封面/正式发布日期识别最新国网范例。
- [ ] 已完整阅读至少 3 项相关最新指南并记录页码。
- [ ] 已用前一批次至少 1 项交叉核对。
- [ ] 已形成当次写作基线和相近指南重复边界。
- [ ] 体例、句式密度、课题粒度与最新范例一致，但内容和阈值不是机械复制。

## C. 术语与专业性

- [ ] 项目名、课题名、关键技术和指标核心术语均为 N/A。
- [ ] 无未定义自造词、宣传词或含义不稳的组合词。
- [ ] 每项内容落到电力系统对象、层级、变量/状态、输入输出和验证。
- [ ] 通用信息技术未成为脱离电力问题的核心研究。
- [ ] 标准条款经过适用性判断，专利权利要求已核对。

## D. 结构与逻辑

- [ ] 七个一级部分齐全，非技术字段未被擅改。
- [ ] 应用场景、功能需求、关键技术、课题、指标和应用逐级对应。
- [ ] 功能需求项数、关键技术项数和课题数相等，且顺序一一对应。
- [ ] 每个课题有三个递进研究点。
- [ ] 每个课题严格使用 5 个连续段落：课题标题、预期目标、指标（1）、指标（2）、指标（3）。
- [ ] 指标（1）、（2）、（3）分别承担核心成果与性能、验证对象与场景、成果产出；无平行的“主要研究内容”“预期成果”“知识产权与论文”小标题。
- [ ] 课题输入输出连续，无重复对象/方法和循环依赖。
- [ ] 跨课题冲突已解决并有报告。
- [ ] 工程矛盾、研究空白和项目增量三张表逻辑一致，每项关键技术有原子证据 ID。

## E. 指标和成熟度

- [ ] 每项比例/比较指标有公式、场景、数据、基线、阈值依据和失败条件。
- [ ] 证据不足的阈值明确待可研/预试验标定。
- [ ] 文献算例值未直接复制为验收阈值。
- [ ] 每个正式指标均有指标卡；字段不完整的指标未写入无依据数值阈值。
- [ ] 成果数量与周期、经费和工作量匹配。
- [ ] 各类成果成熟度分别设置，验证环境与等级一致。

## F. 文档与视觉

- [ ] 原始文件未覆盖。
- [ ] 指南建议稿以 `assets/sgcc-guide-fixed-template.docx` 为母版生成，未从空白 DOCX 重建。
- [ ] 使用 A4 纵向和 3 个分节；封面、目录、指南组页、项目正文顺序正确。
- [ ] 页边距为上 2.80 cm、下 2.50 cm、左 2.80 cm、右 2.60 cm；页眉距 1.50 cm、页脚距 1.60 cm。
- [ ] 封面、目录、页眉页脚、页码、字体、字号、缩进和固定 28 pt 正文行距符合 `fixed-guide-format.md`。
- [ ] 正文无 Word 表格，考核指标为连续段落。
- [ ] 目录项目名与正文完全一致，目录域已更新或文字/页码已人工核对。
- [ ] 无标黄、批注、修订、TODO、占位符和编辑括号。
- [ ] 无异常字距、空格、破折号、断行、孤行、跨页标题或大段空白。
- [ ] DOCX/PDF 已逐页渲染检查；XLSX 每表已预览或结构检查。
- [ ] DOCX/XLSX 可正常打开，ZIP 结构、公式和关系无错误。
- [ ] `scripts/check_guide_docx.py` 返回 `passed: true`，不存在固定格式错误。
- [ ] 决策版综述、一页总结汇编、详细证据附件、固定指南和证据系统工作簿均从同一结构化事实源生成。
- [ ] 构建清单记录输入哈希、核验日期、缓存命中、变化资源和受影响成果；增量构建未遗漏依赖项。

任一必需项未通过时，不得声称全部完成；保存已完成成果、给出比例和下一断点。
