# 期刊追踪说明

能元每天自动抓取以下 9 本期刊的新文章，存进论文库，进入能元的检索、问答和知识库。页面入口：侧边栏「期刊追踪」（`/journal-watch`）。

| 期刊 | 出版平台 | 摘要来源 |
|---|---|---|
| IEEE Trans. Power Systems / Sustainable Energy / Smart Grid / Power Delivery | IEEE Xplore | IEEE Xplore API（key 生效后），否则 OpenAlex |
| MPCE、CSEE JPES、PCMP（开放获取） | IEEE Xplore | 同上 |
| Electric Power Systems Research、Applied Energy | Elsevier | OpenAlex（约 85% 有摘要） |

## 工作方式

1. **新文章清单**：从 Crossref 取。Crossref 是出版商登记 DOI 的地方，清单最全，免费，不需要任何权限。
2. **补摘要**：IEEE 期刊用 IEEE Xplore 官方 API；其余文章用 OpenAlex。新文章刚上线时数据库可能还没有摘要，系统会在之后 120 天里每天重试。
3. **入库**：每篇文章写成一条论文记录（编号 `journal:<DOI>`），能元的检索、问答、知识库都能用到题目和摘要。
4. **开放获取全文自动下载**：每次抓取后，自动下载并解析入库两类公开授权的全文（每篇间隔几秒，每次最多 40 篇，失败的最多重试 3 次）：
   - IEEE Xplore 上的开放获取文章：MPCE、CSEE JPES、PCMP 全部，以及四本 Transactions 里作者付费开放的文章；
   - OpenAlex 记录的开放仓储版本（多为 arXiv 预印本，页面标「预印本已入库」，内容可能与正式版略有不同）。
   - Elsevier（EPSR、Applied Energy）的开放获取文章暂时下不了：ScienceDirect 网页禁止程序下载，Elsevier API key 也还没开通全文权限。
5. **订阅文章的全文**：需要全文时，在页面点「原文」用机构账号手动下载 PDF，再点「上传全文」。系统会解析 PDF、按正文建索引，并用全文记录替换原来的摘要记录。PDF 保存在 `数据/论文/期刊追踪/<期刊>/`。
   - 之前已经导入过的同一篇论文（DOI 或题目相同），抓取时会自动对上，不会重复。

> 不做"用机构账号自动批量下载 PDF"：IEEE 和 Elsevier 的条款禁止，被发现会封掉整个单位的访问。

## 定时与配置（`.env.local`）

| 变量 | 默认 | 说明 |
|---|---|---|
| `JOURNAL_WATCH_ENABLED` | `1` | 设为 `0` 关闭定时抓取 |
| `JOURNAL_WATCH_HOUR` | `3` | 每天几点之后抓（服务器本地时间） |
| `JOURNAL_WATCH_BACKFILL_DAYS` | `30` | 第一次运行往前抓多少天 |
| `JOURNAL_WATCH_OA_DOWNLOAD` | `1` | 设为 `0` 关闭开放获取全文自动下载 |
| `JOURNAL_WATCH_OA_MAX` | `40` | 每次最多自动下载多少篇 |
| `IEEE_XPLORE_API_KEY` | 空 | IEEE Xplore API key |
| `OPENALEX_API_KEY` | 空 | OpenAlex key |

定时任务由 worker 进程负责：到点后排一个 `journal-watch` 后台任务，失败的 2 小时后重试，同一天成功后不再重复。

## 手动运行

- 页面上管理员可点「立即抓取」。
- 命令行：

```bash
npm run journal:watch                 # 从上次成功之后抓
npm run journal:watch -- --days 90    # 往前补抓 90 天
```

## 代码位置

- `src/lib/journal-watch/journals.ts`：期刊清单（增删期刊改这里）
- `src/lib/journal-watch/sources.ts`：Crossref / OpenAlex / IEEE Xplore 接口
- `src/lib/journal-watch/run.ts`：抓取流程、入库、全文对接
- `src/lib/journal-watch/scheduler.ts`：每日定时
- `src/app/api/journal-watch/`：页面用的接口；`src/components/journal-watch-page.tsx`：页面
- 数据表：`journal_watch_articles`（文章）、`journal_watch_runs`（每次抓取记录）
